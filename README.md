# GroknMok

A small command-line client that searches a published snapshot of
independent hobby stores' online stock, offline, with optional live
confirmation of matches and restock alerts.

Status: early development. Not yet released.

## Dataset notice

Provided for use with GroknMok only; no redistribution. Product facts
belong to the stores. Not affiliated with Games Workshop.

Store owners who want their store left out: contact OPTOUT_CONTACT.
